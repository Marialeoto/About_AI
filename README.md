# 🧠 About_AI

## Documentación clara y práctica sobre Inteligencia Artificial

Bienvenida/o a **About_AI**, un repositorio vivo donde documento de forma clara y ordenada todo lo que voy aprendiendo sobre Inteligencia Artificial.

Este espacio no es teoría abstracta ni contenido técnico innecesario. Es **aprendizaje real**, explicado de manera simple y pensado para personas que quieren **entender, aplicar y avanzar** con IA.

---

## 🎯 ¿Para quién es este repositorio?

Este repositorio es ideal si:

- Quieres entender IA sin humo ni tecnicismos excesivos  
- Estás empezando y necesitas una guía clara  
- Usas herramientas como ChatGPT, Geminis, Perplexity, Claude o Midjourney  
- Buscas casos prácticos y ejemplos reales  
- Prefieres aprender leyendo, paso a paso  

---

## 🗺️ Mapa del Repositorio

Puedes leer el contenido en orden o ir directo a la sección que necesites:

### 📘 01 – Fundamentos
Conceptos esenciales sobre IA, LLMs, redes neuronales y terminología clave.

### 🧩 02 – Prompt Engineering
Guías y técnicas para comunicarte mejor con las inteligencias artificiales.

### 🛠️ 03 – Herramientas
Tutoriales prácticos sobre ChatGPT, Claude, Midjourney y otras herramientas.

### 🧪 04 – Tutoriales Prácticos
Casos de uso reales y proyectos explicados paso a paso.

### 🔗 05 – Recursos
Libros, enlaces externos y herramientas recomendadas para seguir aprendiendo.

---

## 🚀 Cómo usar este repositorio

1. Comienza por **Fundamentos** si estás iniciando.  
2. Explora **Prompt Engineering** para mejorar tus resultados.  
3. Usa **Tutoriales Prácticos** para aplicar lo aprendido.  
4. Guarda el repositorio y vuelve cuando haya contenido nuevo.
